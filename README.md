# Shubham Coffee House

Build a complete premium 3D animated coffee shop website named **SHUBHAM COFFEE SHOP** with a fully functional Admin CRM Dashboard.

**IMPORTANT: Build the complete working application, not just a UI design or prototype.**

### 1. Customer Website
- Premium cinematic coffee-themed design.
- Real 3D rotating coffee cup, floating coffee beans and steam animations.
- Smooth GSAP scroll animations and Framer Motion transitions.
- Home, About, Menu, Shop, Cart, Checkout and Contact pages.
- Product details, search, filters and categories.
- Fully functional shopping cart and demo checkout.
- Responsive desktop and mobile design.

### 2. Admin CRM Dashboard
Create a separate professional SaaS-style admin panel with:
- Admin Login / Logout
- Dashboard with dynamic statistics and charts
- Customer Management (Full CRUD)
- Order Management (Full CRUD + status updates)
- Product Management (Full CRUD)
- Category Management
- Inventory Management
- Enquiry Management
- Employee Management
- Offers & Coupon Management
- Reports & Analytics
- Business Settings

### 3. Complete Functionality
- Customer orders must automatically appear in Admin CRM.
- Admin product changes must reflect immediately on the website.
- Automatically update customer records.
- Automatically deduct inventory after successful orders.
- Restore inventory when orders are cancelled, exactly once.
- Contact enquiries must appear in Admin CRM.
- Coupons and discounts must work during checkout.
- All dashboard statistics must be dynamically calculated.
- Search, filters, validation, confirmations and notifications must work.

### 4. Technology & Data
Use React.js, JavaScript, Vite, Tailwind CSS, Three.js, React Three Fiber, GSAP, Framer Motion, React Router and Lucide React.

**CRITICAL:** Frontend-only application. Use browser LocalStorage for ALL data. No backend, APIs, Firebase, Supabase, MySQL or external database.

Use centralized storage services and React Context for shared state. All CRUD operations must persist after refresh.

### 6. Final Instructions
- Maintain premium design quality throughout.
- Use real working functionality, not dummy buttons.
- Create reusable components and clean architecture.
- Add realistic initial demo data.
- Protect admin routes.
- Ensure all pages and workflows work.
- Test the complete customer-to-admin order workflow.
- Do not leave incomplete modules or placeholder functionality.

**MOST IMPORTANT:** Build the entire project in one implementation. Do not stop after the homepage. Every customer and admin module must be connected and functional using LocalStorage.

Final result should look and function like a premium commercial coffee shop website with a complete business management CRM.
